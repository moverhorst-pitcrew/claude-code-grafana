# Code of conduct

Be respectful and constructive. Harassment, personal attacks and discrimination are not welcome in issues,
pull requests or discussions.

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report conduct problems privately through GitHub (a security advisory or a message to the maintainer); the maintainer
may edit or remove contributions and block people who do not follow it.
